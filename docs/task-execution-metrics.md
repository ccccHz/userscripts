# 执行任务模型与消耗实验账本

本页用于比较不同派生任务模型的完成质量、耗时和额度变化。账户窗口百分比是 Codex 提供的总体粗粒度
指标，不等于逐任务精确 token；并发任务、调度对话和其他 Codex 使用都会污染差值。

## 记录字段

| 字段 | 说明 |
| --- | --- |
| 任务与 task/thread ID | 可追溯到唯一派生任务 |
| 模型 / reasoning | 必须显式记录，不依赖默认值 |
| 样本类型 | 实现、验收、复核/补救或中止 |
| 范围与规模 | package、功能簇、主要文件和验收矩阵 |
| 开始/结束与墙钟 | 使用任务状态时间；等待用户时间另注 |
| 5 小时 / 每周窗口前后 | 总体 usedPercent；缺失或并发即标污染 |
| 工作分解 | 需求确认、代码、自动化测试、Computer Use、文档各自轮次/命令数 |
| 返工 | 核心体验返工、普通缺陷修复、用户澄清次数 |
| 结果 | 完成、verifying、blocked、system error 或用户叫停 |
| 可比性 | 有效、辅助或无效，并说明原因 |

  独立可见任务对话”规则，因此标记为**旧流程辅助样本**。模型配置真实且符合 Terra High，可用于粗略比较
  同模型代码/门禁轮次；不能作为“独立任务 one-shot 流程”、完整浏览器验收耗时或精确 token 的有效样本。
