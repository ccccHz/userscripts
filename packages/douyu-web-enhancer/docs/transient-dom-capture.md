# 瞬态 DOM 采集指南

适用：短暂弹窗、活动横条、播放器飘屏弹幕、付费弹幕浮层等会自动消失的页面元素。
这是按需使用的调研方法，不是每项开发的强制门禁，也不是正式 runtime 实现要求。

## 2026-09-27 复盘：为何此前漏掉、后来成功

房间 52 的徽章与亲密度提示证据见 [专项记录](research/room-entry-prompts.md)。

- 早先主要做即时 DOM 查询，查询时间不覆盖目标可见窗口；消失后的空查询不能证明未出现。
- 最初的 Observer 把 40 秒等待和结果返回绑在一次 CDP 调用中，工具约 20 秒超时。
  结果仅存于未返回 Promise 的局部变量，没有再次读取的入口，无法恢复证据。
- 每次变更扫描整个 body、仅匹配直接文本节点，分别带来负担和嵌套文案漏匹配风险。
  这些是方法缺陷；没有证据可断言哪一个单独导致某次漏捕。
- 成功轮次在刷新后约 0.64 秒接入 Observer，命中即时保存，安装立即返回，分段读取。
  捕获徽章节点约 13.2 秒创建、BUFF 约 24.5 秒出现。首轮补采只接入于约 24.6 秒，
  能捕获 BUFF 却错过徽章，进一步说明接入时机重要。
- 找到真实节点后，再以 40 秒有界、250ms 的双节点定向采样补可见生命周期。
  徽章约 23.0 秒可见、24.5 秒消失；BUFF 约 26.0 秒可见、30.8 秒消失。
  采样时刻不是精确站点计时，卡顿会延迟采样。

## 推荐流程

1. **确认环境和范围**：记录浏览器、URL、页面模式及是否有当前主项目 DEV。
   原生 DOM 调研不依赖 DEV；脚本验收必须确认当前主目录构建实际运行。
2. **提前接入**：先准备完整采集表达式，刷新与安装放在同一次编排中连续执行，
   避免刷新后临时编写采集器。记录接入时的页面毫秒数，明确导航到接入之间仍有盲区。
   仅当工具实际支持时才使用导航前注入接口；不要把不支持的接口当作已完成。
3. **发现阶段**：已知宿主就局部观察；未知宿主可短时观察 body 的新增/变化子树，
   但不对每次变更重新扫描全页。检查新增节点及后代、变化文本的父节点；匹配嵌套文案。
   初始扫描一次现有节点，避免接入前已创建的节点遗漏。
4. **命中即时存证**：最小目标节点、必要父链和样式立即序列化保存。
   不只保留元素引用：脱离文档后，样式和几何可能已无法还原。
5. **分段读取**：采集器安装调用立即返回，短调用读取缓冲区；不要长时间等待后才返回。
   数据可短暂保存在当前页面的独立、唯一命名对象中，不写 Cookie、账号存储或永久全局。
   下一次刷新前先读取并带回宿主侧，否则页面重载会清空缓冲。
6. **定向补证**：识别真实组件后，缩小范围，补可见状态、自然移除/隐藏和相邻保留区域。
   有足够证据即停止，不反复刷新制造重复样本。
7. **结束清理**：disconnect Observer、清理计时器、移除临时采集对象；报告是否留下页面修改。
   将脱敏的结构与结论保存到主项目文档，不把调研探针塞进正式功能。

## 记录内容与上限

- 导航相对时间与采集时刻；事件为创建、更新、可见、隐藏还是移除。
- 最小 `outerHTML`、class/id/data/role、必要父链；不导出整个 body 或聊天列表。
- `display/visibility/opacity/position/z-index/pointer-events`、bounding rect。
- 背景图片、图片子层、必要的 `::before/::after`；文字颜色/阴影仅在可读性相关时采集。
- 限定总时长、记录数和每条/总字节数，例如一次 40–90 秒、最多 12 个候选、
  每条 HTML 最多 16KB；具体上限按问题调整，溢出必须注明截断，不能冒充完整样本。
- 同一节点的同一状态去重，但不能把“创建时已记录”作为忽略之后可见状态的理由。
  倒计时每秒更新一般只记初值、终态，不无限保存。

`display:block` 或 `visibility:visible` 不等于用户可见：还需检查 opacity、尺寸、父层隐藏、
视口位置/裁切，必要时补截图。飘屏元素有正尺寸也可能在屏外；几何不能单独证明未被遮挡。

## 飘屏弹幕怎么应用

- 优先观察已确认的播放器弹幕宿主，如本项目样本中的 `#comment-higher-container`；
  宿主可能重建，先确认当前页面，必要时观察稳定父层以重新绑定。
- 只解析新增弹幕根及其后代，命中后立即保存结构、内联样式、图片层与伪元素。
  不等待它飞完，也不在每条新弹幕到来时扫描已有整批弹幕。
- 用真实 DOM 身份（如 `data-comment-uuid`）或节点身份去重，不只用正文；
  同一句话可能来自不同类型或不同用户，正文相同不等于结构相同。
- 采集“普通、彩字、背景、头像、表情/图片”等代表类型，达到类型覆盖后停止。
  保留结构但省略正文、昵称、头像 URL 和消息标识值，避免把聊天数据纳入仓库。
- 创建瞬间可能还未布局：先存 DOM，再以一次后续渲染采样或短时定向复采补样式/位置。
  不依赖低频轮询抓到每条飞行弹幕；短时采样只用于已捕获对象的状态补证。
- 当前背景 DOM 与最终图片资产可能由客户端渲染决定；WebSocket 数据不能替代最终 DOM 证据。

## DevTools 暂停作为兜底

可在已定位容器设置 subtree modification 断点，在目标插入时暂停并检查 DOM。
飘屏宿主变更频繁，应先限定目标，避免每条弹幕都暂停。暂停 JS 不保证冻结 CSS 动画、
视频或合成线程，也会改变加载时序；断点结果证明结构，不自动证明正常生命周期。
调研结束移除断点并恢复执行。

## 安全和结论边界

只读采集可临时安装观察器，但不隐藏目标、不点击佩戴/领取、不清 storage、不改响应或伪造消息。
需要账号操作仍须单独授权。文案用于发现候选，不直接变成正式隐藏规则：本次泛文案匹配还命中
了无关活动挂件“5.4倍亲密度”，必须通过真实组件结构排除。

空结果、工具超时、页面卡顿都只说明证据不足。先查接入时间、匹配方式、观测范围、
iframe/Shadow DOM 和缓冲返回链路；不要直接判断功能不存在或账号不符合条件。
