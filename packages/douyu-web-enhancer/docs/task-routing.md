# 调度中心任务编排

本文件只约束 DouyuEx / `douyu-web-enhancer` 调度方式，不替代模型的工程判断。其他 userscript 项目不在本调度中心处理。目标是通过清晰的上下文隔离和完整验收，减少用户纠偏与跨任务返工。

## 当前实验配置

- 调度中心保持当前模型配置。
- 独立执行任务默认显式使用 `gpt-5.6-luna` / `high`；用户为具体任务另行指定时覆盖默认值。
  这是 2026-09-19 基于直播时移控制与自动最高画质样本调整的实验参数，不是永久结论。
- 每个任务记录实际模型、推理等级和可获得的额度数据；无法取得精确 token 时只写估算并标记污染。

## 选择任务形态

- **独立可见任务**：完整 feature、跨阶段实现、需要浏览器验收或用户反馈、需要单独统计成本的工作。
- **内部 subagent**：只读检索、API 调研、独立审查、测试矩阵等边界明确且可压缩为短结论的辅助工作。
- **调度中心直接完成**：几分钟内可完成、不会修改 package 功能或污染主要上下文的检查与规则维护。

独立任务是交付物的持续负责人。同一 feature、界面或内聚模块的实现、补功能、直接修复和补充验收，默认继续原独立任务；“这一轮可独立验收”不构成新建理由。subagent 只能复用原辅助角色，不能接管 feature 主线。

新建任务前必须先在任务列表中查找同一交付物的已有负责任务。只有交付物已改变、原上下文已混杂或不可用、或确有独立长期维护边界时才新建，并在派发前向用户说明理由。无法确定时优先续用，而不是预防性拆分。

## 派发流程

1. 调度中心先从归档源码、当前页面、代码和既有证据整理事实，只向用户询问会改变体验、范围、状态或验收的问题。
2. 反复澄清实质性歧义后，向用户复述并确认一份书面冻结契约。契约至少包含：
   - 原始体验目标和可见成功结果；
   - 原版行为与当前实现；
   - 必做范围、非目标和保留区域；
   - 状态、持久化、触发、用户接管及失败边界；
   - 可在浏览器复现的验收步骤与所需授权；
   - 相关源码、契约、测试和文档入口。
   契约只有在以下事实都已确定后才能标记“已冻结”：
   - “原版/官方/现有”分别指归档 DouyuEx、当前斗鱼页面还是当前增强脚本；
   - 目标的精确页面区域、触发动作和用户可见结果，不用“弹幕功能”之类概括代替；
   - 要求与当前官方 UI 等价时，已采集目标界面的真实截图和 DOM，并把文案、图标、顺序、位置、状态变化写成可验收事实。
   缺少可复现样本时保持“待调研/等样本”，不得用归档选择器或功能名称补全当前体验。
3. 先查找该交付物的已有负责任务：有则显式续派；只有符合上述新建条件时才创建侧栏可见任务并说明理由。显式传入当前实验模型，只提供冻结契约、必要路径、已知证据、权限边界和验证命令，不复制整个调度历史。
4. 执行任务先做实施前事实校验：确认契约的目标 DOM、页面区域和样本状态与当前页面一致。归档代码只能证明历史语义，不能代替当前 DOM 证据。若不一致或核心路径无法复现，暂停实现并返回调度中心，不得自行猜测。通过后再在同一契约下完成代码、测试、文档和可安全执行的浏览器验收。
5. 每份冻结契约必须指定唯一的真实浏览器验收负责人。默认由独立执行任务负责，使实现、修正和真实体验闭环在同一上下文；若执行任务无法安全操作浏览器，或用户明确要求集中验收，才改由调度中心负责。
6. 调度中心审核实际产物、测试结果和浏览器证据，但不重复已由负责人完成且证据充分的 Computer Use 路径。只有证据缺失、互相矛盾、改动触及高风险边界或用户报告与结果不一致时，才做最小定向复验；用户明确完成的实测同样计入验收证据。

one-shot 指同一独立任务可自行迭代直至交付，不需要用户反复纠正核心体验；不表示只能有一次模型回复。受账号授权、安装或罕见自然事件阻塞时可保持 `verifying`，但不得把普通核心路径遗漏包装成完成。

## 浏览器验收去重

- Computer Use 属于高成本但高价值的真实用户端验证，不能因成本而省略，也不能由执行任务、调度中心和用户机械重复。
- 派发时写明浏览器验收负责人、页面样本、允许的操作、禁止的账号动作和需要回传的证据。负责人应回传版本、页面状态、关键操作结果、未覆盖项及必要的截图或几何/日志证据。
- 调度中心的“独立验收”首先是独立判断证据是否充分，不等于再次操作浏览器。已有充分证据时只做代码/产物/记录一致性核对。
- 若验收责任临时转移，先记录原因和已经完成的步骤，再从缺口继续；不得从头重跑。用户已经手动验证的路径也按同样方式记录并复用。
- 需要复用真实 Chrome 登录态测试斗鱼接口时，验收负责人定向读取
  `packages/douyu-web-enhancer/docs/authenticated-api-testing.md`；不要把 DevTools Console 强行作为跨域执行器，
  也不要为一次测试把临时探针留在正式 runtime。

## 记录

在同目录 `task-execution-metrics.md` 记录任务 ID、实际模型/推理等级、起止时间、实现与返工轮次、测试和浏览器验收耗时、未覆盖项及可获得的额度变化。记录只服务比较，不为制造样本重复已经完成的代码或账号动作。

可逆、非账号性的契约内浏览器操作可直接用于验收。发送消息、签到、送礼、关注、登录、付费、修改账号状态或删除数据仍须逐项获得用户授权。
