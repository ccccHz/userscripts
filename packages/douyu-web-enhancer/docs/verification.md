## 统一验收模板

每个迁移功能在标记为 `done` 前必须留下以下四层证据；缺少任一层时只能保持
`implementing` 或 `verifying`。

1. **配置层：** 默认值、保存值、刷新及切换房间后的读取结果。
2. **运行时层：** feature 启用、停用、重复启用幂等性和清理结果。
3. **页面结果层：** 目标节点的计算样式、可见性、尺寸或位置；同时检查契约列出的保留区域。
4. **体验层：** 页面内入口的位置、文案、操作步骤、启停反馈及与归档基准的差异。

实机记录至少包含目标 URL、普通/网页全屏/浏览器全屏模式、相关独立开关组合、刷新、切换房间、
启用和停用恢复。DOM 节点存在、CSS 已注入、按钮 `aria-pressed` 正确或测试通过，均不能替代
页面结果层和体验层证据。
