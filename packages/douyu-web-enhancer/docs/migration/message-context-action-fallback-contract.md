## 原始体验目标

斗鱼会根据房间配置与用户条件，选择性提供弹幕右键卡片中的“回复”和“+1”，甚至同时取消。用户希望
无论官方是否授予这两个快捷入口，增强脚本都逐项补齐缺失操作；官方已有的操作必须保留并优先使用，
不能出现重复按钮。

当前样本的普通文字弹幕卡片显示“赞 / 举报 / 回复 / 收藏”，没有“+1”，可验证“回复保留、只补 +1”。

  原版无条件插入“回复”，点击后以 `@用户名：原弹幕` 覆盖输入框并聚焦，不自动发送。
- 归档 +1 实现：
  `archive/douyuEx-2026.06.03.01/source/src/packages/BarragePanel/BarragePanel_Tip.js`。
  原版无条件插入“+1”，点击后立即调用发送逻辑发送所选弹幕正文；图片分支依赖已放弃迁移的

- 原版不判断官方入口是否存在，容易重复；选择器为旧版哈希类名，且没有现代的生命周期、清理与失败边界。
- 当前增强脚本已有分房间发送历史、发送回显检测和统一控制中心，但尚未迁移右键操作补全。

## 本次必须实现

- 作为一个内聚功能实现“回复”和“+1”的逐项缺失补全，但两个能力分别判断、分别诊断。
- 仅作用于 `www.douyu.com/<数字房间号>` 直播页的普通用户文字弹幕卡片。
- 官方已有某项操作时不插入脚本版本；只有该项在稳定渲染后的正常卡片中缺失时才补充。
- 支持所有组合：两项都有、只有回复、只有 +1、两项都没有。官方入口始终优先。
- 如果官方按钮稍后动态出现，立即移除对应脚本按钮，不能形成重复或遮挡。
- “回复”点击后按当前斗鱼官方语义把目标作者与正文填入发送输入框并聚焦，只填充、不发送。
- “+1”点击后立即发送一次所选弹幕的纯文字正文；这是用户主动点击触发的账号动作，不自动执行、
  不自动重试、不循环发送。
- +1 发送过程中保留用户原有草稿与光标/选择状态，动作结束后恢复草稿；发送结果接入现有发送历史与
  两秒回显检测，不建立第二套发送队列或结果判断。
- 在卡片打开时绑定目标消息快照，避免弹幕滚动、虚拟列表复用或卡片切换后发送错误消息。
- 默认开启，在控制中心“弹幕”分区提供独立全局开关；关闭后移除所有注入按钮、监听、观察与缓存。
- 复用现有 settings、runtime、diagnostics、共享 observer 和输入/发送适配层；实现必须幂等、可撤销，
  不使用永久轮询。

## 缺失判定与缓存

- “回复”和“+1”分别保存当前房间生命周期内的能力结论。
- 只有结构完整、作者与纯文字正文明确、官方操作区稳定的普通用户弹幕卡片才能形成“官方缺失”结论。
- 第一次稳定确认某项缺失后，同一房间生命周期的后续合格卡片可直接补充，避免反复进行完整能力探测；
  每张卡片仍须检查官方按钮是否实际存在，官方动态出现时撤回脚本按钮。
- 刷新、真实 SPA 房间号变化或登录身份变化后重新判定；不把权限结论永久保存到本地。
- 系统消息、礼物、进场、主播通知、自身不允许操作的消息、正文为空、纯图片或结构不完整的卡片既不注入，
  也不能污染能力缓存。

## 明确不实现

- 不补“赞、举报、收藏、查弹幕、禁言”等其他右键操作。
- 不绕过服务端发送、禁言、频率、长度或内容限制；+1 只是把用户可手动发送的同一纯文字走现有官方发送路径。
- 不迁移 DouyuEx 图片弹幕，不复读图片、礼物、系统消息或富媒体 HTML。
- 不自动点击官方操作，不自动回复，不根据弹幕内容触发发送。
- 不新增网络域名、userscript 权限、外部依赖或账号接口。

## 状态与异常边界

- SettingsStore 是开关的唯一持久化事实来源；每房间能力缓存、当前卡片消息快照和发送动作属于页面内存。
- 卡片关闭、消息节点复用、输入区/卡片重建、SPA 换房和停用均须清理陈旧目标与派生 DOM。
- 无输入框、发送按钮不可用、文本为空/超限、账号限制或发送适配失败时不发送，给出本地失败反馈，
  保留原草稿且不重试。
- 官方 DOM 语义无法可靠确定时安全降级，不猜测插入，不改变官方卡片布局或其他按钮行为。

## 浏览器验收

唯一真实浏览器验收负责人：独立执行任务；真实 +1 发送由用户最终手动验收，除非用户另行逐次授权。

使用最新 `dist` 和上方样本：

1. 打开普通用户文字弹幕卡片，确认官方“回复”原样保留且只有一个，脚本只补缺失的“+1”。
2. 连续打开不同普通弹幕，确认按钮不重复、目标正文快照不串行，卡片重建后仍正确。
3. 验证官方按钮延迟出现时脚本对应按钮撤回；无法在真实样本触发时由自动化 DOM 测试覆盖并标记实机缺口。
4. 在存在官方回复的当前样本中不替换、不劫持官方回复；若找到缺失回复的自然样本，验证脚本回复只填充并聚焦，
   不发送，且文本/作者格式匹配当前官方行为。
5. 系统、礼物、进场、空正文和富媒体卡片不注入，也不影响后续普通弹幕的能力结论。
6. 关闭开关后注入入口立即消失；重新开启、刷新、网页全屏/控制区重建和安全可行的 SPA 换房后正确恢复。
7. 执行任务不得点击脚本 +1；只验证按钮、目标快照、发送前保护和单次调用自动化测试。用户自然点击后验证：
   只发送一次正确原文、原草稿恢复、发送历史与回显检测接线正常。

不得为寻找样本发送弹幕、点赞、举报、收藏或执行其他账号动作。
