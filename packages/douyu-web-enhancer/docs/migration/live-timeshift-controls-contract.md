# 直播时移控制冻结契约

状态：**已冻结，可执行**

确认日期：2026-09-19
验收样本：`https://www.douyu.com/5135383?dyshid=16c8694-a12f0ece4ef4b08c1fe4763e00091701`

## 原始体验目标

部分正在直播的斗鱼房间提供可回看的实时进度条。用户希望在这种直播间内直接用键盘左右键前后跳转，
并能通过播放器附近的“同步时间”动作回到直播最新位置；普通无时移直播间和文字输入体验不能受到影响。

## 原版行为与当前实现

- 归档 `VideoRecall` 在 `document` 捕获阶段监听左右键，将视频 `currentTime` 加减 3 秒；只排除输入元素，
  只把下界限制为 0，没有判断直播是否真的可时移。
- 归档 `VideoSync` 在播放器左侧控制区插入“同步时间”按钮，点击后跳到 `buffered.end(0)`；没有处理
  多段区间、播放器重建和完整清理。
- 当前增强脚本尚未迁移这两项能力；控制中心已有“播放”分区，可承载独立开关与运行状态。

- `archive/douyuEx-2026.06.03.01/source/src/packages/VideoTools/VideoSync/VideoSync.js`

## 本次必须实现

- 作为一个内聚交付物迁移“左右键回看”和“同步到最新”，但保留独立模块、运行状态、诊断与清理边界。
- 只作用于 `www.douyu.com/<数字房间号>` 直播页，不作用于 `v.douyu.com` 视频页。
- 仅在当前播放器存在有效 `seekable` 区间时接管左右键；左键后退 3 秒，右键前进 3 秒，允许按住连续触发。
- 每次操作重新读取有效 `seekable` 区间；跨多段区间时钳制到最近的安全边界，不越出可回看范围。
- “同步时间”跳到最后一段 `seekable` 的末端，即当前直播最新位置。
- 跳转不主动改变播放/暂停状态。
- 输入框、`textarea`、`contenteditable`、控制中心、IME 合成、非折叠文本选择和带修饰键的按键均不接管。
- 没有有效时移区间、播放器不唯一或读取异常时，不阻止浏览器/页面原有按键行为；同步入口隐藏或禁用，
  不呈现可用假象。
- 刷新、斗鱼 SPA 换房、播放器/控制区重建和网页全屏退出后能够恢复；关闭功能时移除监听、入口和页面标记。
- 功能默认开启，在控制中心“播放”分区提供独立开关并持久化；“同步时间”是一次性动作，不保存播放位置。
- 复用现有 settings、runtime、diagnostics、共享 observer 和控制中心组件，不引入无界轮询。

## 明确不实现

- 不迁移 `v.douyu.com` 视频页键盘控制。
- 不包含倍速、空格播放、上下键音量、最高画质、离线跳转禁用或播放位置记忆。
- 不增加 toast/HUD，不重绘官方进度条，不尝试扩大官方提供的回看缓冲。
- 不发起任何账号操作，不新增 userscript 权限或外部网络请求。

## 状态、持久化与异常边界

- settings 是持久化设置的唯一事实来源；运行状态由当前页面与播放器能力派生。
- `seekable` 是是否可操作及边界的权威来源；`buffered` 只可用于诊断，不能代替时移能力判断。
- 每次按键或同步动作都重新读取区间，避免直播窗口滑动后使用过期边界。
- 空区间、DOM 重建、媒体异常和非唯一视频节点都安全降级，不吞键、不持续重试、不循环 seek。
- 到达最新位置后停止，不用定时器持续“追直播”。

## 浏览器验收

唯一真实浏览器验收负责人：独立执行任务。调度中心只审核证据，不重复充分路径。

在上方房间样本中使用最新 `dist`：

1. 确认页面有官方可拖动直播进度条，并记录视频 `seekable` 能力。
2. 左右键各按一次，验证约 3 秒跳转且播放/暂停状态不变。
3. 连续按键或按住按键，验证边界钳制且不会越出有效区间。
4. 回看后点击“同步时间”，验证回到最新位置且之后没有持续定时追踪。
5. 在弹幕输入框、控制中心输入项和可编辑区域按左右键，只移动光标，不触发视频跳转。
6. 覆盖网页全屏进入/退出、刷新和播放器重建；安全可行时再覆盖一次 SPA 换房。
7. 在无有效 `seekable` 的状态或房间验证不吞键、不显示误导性的可用入口。
8. 关闭开关后监听和入口消失；重新开启及刷新后设置保持并恢复功能。

真实“按住连续跳转”的手感由用户后续自然使用补充；执行任务仍须完成可自动化的按键、边界和恢复验证。
