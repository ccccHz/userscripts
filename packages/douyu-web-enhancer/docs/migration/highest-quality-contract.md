# 自动最高画质冻结契约

状态：**已冻结，可执行**

确认日期：2026-09-19
验收样本：`https://www.douyu.com/5135383?dyshid=16c8694-a12f0ece4ef4b08c1fe4763e00091701`

## 原始体验目标

斗鱼允许用户手动画质，但不会在每次进入直播间时可靠选择当前账号真正可用的最高画质。启用本功能后，
每次进入直播间应自动完成一次最高画质选择，同时把后续控制权交还用户，不与用户手动降低画质对抗。

## 原版行为与当前实现

- 归档实现位于 `archive/douyuEx-2026.06.03.01/source/src/packages/ExpandTool/ExpandTool_FullScreen.js`。
- 原版设置默认关闭，保存于 `localStorage.ExSave_HighestVideoQuality`，启用提示“刷新页面生效”。
- 页面启动后每秒查询一次画质容器，最多约 100 秒；找到后直接把列表第一项视为最高画质并点击。
- 原版没有可靠处理受限/锁定档位、选择失败、用户手动覆盖、SPA 换房及播放器重建，轮询时间也过长。
- 当前增强脚本尚未迁移此能力；斗鱼官方只提供手动画质选择，不提供自动选择最高画质。

## 本次必须实现

- 仅作用于 `www.douyu.com/<数字房间号>` 直播页。
- 提供全局持久开关，默认关闭；入口位于控制中心“播放”分区，不新增播放器近场按钮。
- 开关在当前页面启用后立即尝试，不要求刷新；关闭只停止后续自动选择，不擅自改变当前画质。
- 每次真实直播间生命周期执行一次：首次进入/刷新、真实 SPA 换房或新播放器实例重建可开始新事务。
- 等待官方播放器与画质菜单达到可操作状态后，选择官方菜单中当前账号可实际点击的最高档位。
- 以官方画质菜单顺序作为档位优先级，跳过禁用、锁定、登录/VIP/付费受限或不可操作项；已经位于最高
  可用档位时不点击。
- 选择后验证官方选中状态或显示标签确实变为目标画质；成功、明确不可用或一次验证失败后结束事务，
  不循环点击。
- 自动选择完成后，用户本页手动选择其他画质即视为接管；同一直播间生命周期内不再抢回最高画质。
- 自动点击引起的播放器/画质控件重建不能被误判为新事务；用户手动选择引起的重建同样不能重新抢回。
- 复用 settings、runtime、diagnostics、共享 observer 和控制中心组件；等待必须有界、可停止且无永久轮询。
- 刷新、网页全屏进入/退出和控制区重建后不产生重复点击；停用后取消订阅和待执行事务。

## 明确不实现

- 不修改斗鱼可提供的画质档位，不绕过登录、VIP、付费、地区或线路限制。
- 不持久化具体画质名称，只持久化功能开关。
- 不实现自动码率、自适应网络测速、失败降档、线路选择或定时重新强制最高画质。
- 不迁移直播倍速；斗鱼官方已有完整倍速功能。
- 不处理主播下播自动跳转；该能力等待真实样本后再评估。
- 不新增网络请求、账号动作、userscript 权限或外部依赖。

## 状态、持久化与异常边界

- settings 是功能开关的唯一持久化事实来源；当前事务、自动点击标记与用户接管只存在于页面内存。
- SPA 的真实房间号变化可以建立新事务；普通 DOM 重建、清晰度切换和网页全屏切换不能重置用户接管。
- 广告、下播、轮播、菜单未出现、选项不可判定、候选不唯一或页面结构异常时安全结束或有界降级；
  不猜测点击，不影响播放器和官方菜单。
- 诊断区分：已是最高、选择成功、用户接管、无可用选项、验证失败和页面不适用。

## 浏览器验收

唯一真实浏览器验收负责人：独立执行任务。调度中心不重复证据充分的路径。

使用最新 `dist` 和上方房间样本：

1. 功能关闭时手动选择较低画质，验证脚本不干预。
2. 在当前页面开启功能，验证无需刷新即可选择最高可用画质，并有正确运行状态/诊断。
3. 已处于最高画质时重新进入，验证不产生多余点击或播放器重载。
4. 自动选择完成后手动改为较低画质，验证本页保持用户选择，不被 observer 或控件重建抢回。
5. 刷新页面，验证开关持久化并在新生命周期再次自动选择最高可用画质。
6. 覆盖网页全屏进入/退出和控制区重建；安全可行时覆盖一次真实 SPA 换房。
7. 检查菜单中的不可用/受限项；若样本不存在，明确记录为未覆盖自然样本，不能假称通过。
8. 关闭功能后刷新，验证不再自动选择且没有订阅、标记或点击残留。

画质切换属于本地、可逆的播放器操作；不得发送弹幕或执行任何账号动作。
