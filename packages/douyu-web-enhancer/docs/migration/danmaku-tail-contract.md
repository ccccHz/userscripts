# 弹幕小尾巴：发送层迁移与验证

更新：2026-10-16。验证中构建保持 `0.10.10`，`publish=false`。

2026-10-19 用户确认的布局更新：弹幕页小尾巴位于日常设置后部，默认折叠，摘要保留开关状态；展开后编辑文字、位置和开关。展开状态仅保留在当前页面，刷新默认折叠，不改变已保存配置；工具栏“尾”直接展开并定位输入框。

## 体验与状态

- 归档 DouyuEx 默认关闭，在聊天工具栏提供入口，支持自定义文字及前缀／后缀；发送按钮或 Enter 提交时改写输入框，再交给官方发送。它没有 Socket 出站 Hook 的证据，且可能撞上网页输入长度限制。
- 当前斗鱼网页在 2016309 的 `div.ChatSend-txt[contenteditable]` 标示 `maxlength=60`。这只是页面输入约束，不能据此推断服务端长度上限。
- 新实现默认关闭，独立 GM 键 `douyu-web-enhancer:danmaku-tail` 保存文字、位置和开关。弹幕工具栏有“尾”快捷入口，控制中心“弹幕”页可编辑、保存和启停。空文字不可启用；关闭或清空后出站包原样发送；刷新与跨房间恢复。测试结束恢复默认关闭且空文字。
- 页面 Hook 仅在已捕获的斗鱼 WebSocket 上，遇到完整且合法的 `type=chatmessage`、唯一 `content` 字段时改写 STT 与包长度；已含相同前／后缀则不重复添加。其他类型、心跳、未知或不完整包、解析失败、超过本地边界的包原样发送。页面关闭时恢复属于本脚本的 `send` 方法。
- 不改变输入框中用户写的内容。输入历史仍记录用户提交的原文；服务端回显、聊天栏及发送检测观察的是实际发出的内容。文字本身不写入诊断计数或日志。

## 最新构建的真实页面证据

内置 Browser 已登录的 2016309，主播下播时仍可发送弹幕。最新 `dist` 刷新后，在控制中心填入 `【尾测】` 并启用后：

1. 短输入 `尾巴测试A` 的出站帧为 `chatmessage.content=尾巴测试A【尾测】`；官方返回 `chatres res=0`，房间 Socket 收到相同正文的 `chatmsg`。
2. 输入框原文精确 60 字，Socket 改写为 64 字；官方同样返回 `chatres res=0`，两个房间连接均收到完整 64 字的 `chatmsg`。这证明已测试的 64 字可越过页面的 60 字限制并公开回显；不声称服务端允许任意更长内容。未将 Cookie、token、UID、消息 ID 或完整原包写入文档。
3. 在正在直播的 1126960，另一个标签的工具栏快捷按钮显示已启用，证明同一设置跨房间读取。官方工具栏只在相应状态显示，离线房间会隐藏；控制中心仍可操作。
4. 验收结束关闭并清空测试尾巴；面板显示“已关闭”。

待补：外部 Chrome 最终兼容性验收、前缀模式的真实发送、官网不同会员输入长度及 64 字以上的服务端边界。单元测试覆盖两种位置、重复避免、STT 转义、畸形／非发言帧和 Hook 清理。
